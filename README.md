# Ayurvedic Medicine ML Research

Research repository for building a personalized Ayurvedic herb recommendation system using machine learning.

## 🎯 Project Goal

Develop an ML system that recommends personalized Ayurvedic herbs based on:
- Disease/condition
- Patient constitution (Prakriti: Vata/Pitta/Kapha)
- Symptoms and severity
- Age, gender, lifestyle factors
- Contraindications and safety
